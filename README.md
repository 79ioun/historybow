# 역사를 지켜라 (History Defense)

폰을 컨트롤러로 써서 PC 브라우저에서 실행되는 탑다운 방어 게임을 조작하는 역사 학습 게임입니다.
고구려(살수대첩) → 고려(대몽항쟁) → 조선(임진왜란) 3편이 이어지는 구조입니다.

## 폴더 구조
```
index.html          PC에서 여는 게임 화면
controller.html      폰에서 여는 컨트롤러 화면
css/
  game.css            게임 화면 스타일
  controller.css       컨트롤러 스타일
js/
  game.js              게임 로직 (스테이지·웨이브·퀴즈·보스 등)
  controller.js         컨트롤러 입력 처리 + PeerJS 연결
assets/images/         배경·캐릭터·아이콘 PNG 전부
LICENSE                MIT 라이선스
```

파일이 다 분리되어 있어서, `css/game.css`나 `js/game.js`만 열어서 바로 수정하면 됩니다.
이미지도 `assets/images/`에 실제 PNG 파일로 들어있어서 Photoshop 등으로 바로 교체 가능합니다.

## 로컬에서 실행
1. **PC**: `index.html` 더블클릭 → 6자리 코드 표시됨
2. **폰**: `controller.html`을 폰으로 전송해서 열고, 코드 입력 → 연결
3. PC 화면에서 "게임 시작" 클릭

인터넷 연결이 필요합니다 (PeerJS 무료 공용 서버로 코드 기반 연결을 하기 때문). 같은 Wi-Fi가
아니어도 연결 자체는 되지만, 같은 Wi-Fi에서 가장 안정적으로 동작합니다.

## GitHub Pages로 배포하기
1. 이 폴더 전체를 GitHub 저장소에 푸시합니다.
2. 저장소 **Settings → Pages** 에서 Source를 `main` 브랜치, 루트 폴더로 설정하고 저장합니다.
3. 잠시 후 아래 두 링크가 생깁니다.
   - `https://<아이디>.github.io/<저장소이름>/` (게임)
   - `https://<아이디>.github.io/<저장소이름>/controller.html` (컨트롤러)
4. 두 링크를 공유하면 각자 PC/폰에서 열기만 하면 됩니다.

## 보안 참고
- 연결 코드는 게임을 열 때마다 새로 랜덤 생성되는 6자리 영숫자입니다 (혼동되는 0/O, 1/I 제외).
- 첫 번째로 연결된 컨트롤러만 인정되고, 이후 다른 연결 시도는 자동 거절됩니다 (선착순 1인 잠금).
- 받은 입력값은 이동/발사 상태만 반영할 뿐 실행되는 코드가 아니라서, 낯선 사람이 코드를 맞춰
  끼어들어도 할 수 있는 일은 게임 캐릭터를 대신 조종하는 것뿐입니다.

## 게임 구성
- **1편 고구려**: 수나라 침입 → 살수대첩(을지문덕)
- **2편 고려**: 몽골 침입 → 강화천도·팔만대장경
- **3편 조선**: 임진왜란 → 한산도대첩(이순신)
- 각 편마다 웨이브 전투 2회 + 역사 퀴즈 2문항 + 보스전으로 구성
- 정답을 맞히면 8초간 공격력 2배 버프 + 필살기 이펙트 연출

## 참고 출처
- PeerJS 공식 문서: https://peerjs.com/client/api/peer
- 갑옷·배경 고증 참고 자료는 각 프롬프트 작성 과정에서 개별 검색으로 확인했습니다
  (고구려 찰갑·종장판주, 고려 강화도 토성, 조선 두정갑, 명광개, 몽골 갑옷, 왜군 아시가루 등).
